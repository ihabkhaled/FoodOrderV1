# v1.8.0 Bucket Templates + Account Safety + UX Depth — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Spec: `docs/superpowers/specs/2026-07-29-v1.8.0-design.md` (read it first).

**Goal:** Ship the 11 v1.8.0 features as 11 independently tested, committed, and
gate-checked phases on `release/1.8.0/bucket-templates-ux`.

**Architecture:** Module-first layered tree (`app → modules → shared/platform → packages`)
with mechanical ESLint enforcement; dual cloud/local persistence behind `data-access`
contracts; 12-locale hand-rolled i18n; native `<dialog>` UI primitives in `src/shared/ui`.
Every phase follows: targeted tests → lint+typecheck×2 → conventional commit → push →
Branch Continuous Release ladder green (`gh run list/watch`) before the next phase.

**Tech Stack:** React 19, Vite 8, TS 7.0.2 + 5.9.3, Vitest + Testing Library, Playwright
(6-project matrix), Capacitor 8, Firebase (Auth/Firestore/Functions callables), lucide-react
via `@/packages/icons`.

## Global Constraints

- Every user-visible string: keys in ALL 12 locales (`en, ar, it, fa, fr, de, es, pt-BR, hi, th, zh-CN, ja`) of the owning catalog; `npm run i18n:check` must pass.
- File naming: kebab-case + responsibility suffix (`.component.tsx` hook-free, `.container.tsx`, `use-*.hook.ts`, `.helper.ts`, `.adapter.ts`, `.types.ts`, `.constants.ts`, `.interfaces.ts`, `.enums.ts`); declarations only in declaration owners.
- Browser globals only in `src/platform`; vendor imports only in owning `src/packages/*` facade; registry entry in `eslint/package-ownership.config.mjs` BEFORE first import.
- No `enum` keyword; `as const` objects. No new store/query libraries. UI never calls Firebase directly.
- Never weaken `firestore.rules`; rules changes need emulator tests (`npm run test:rules`, requires JDK 21).
- `.ai/` is generated: run `npm run knowledge:build:incremental` after canonical doc edits; never hand-edit.
- Hooks are never bypassed; conventional commits (`feat|fix|docs|refactor|test|chore(scope): ...`).
- Per-phase validation minimum: `npm run lint:fix && npm run lint`, `npm run typecheck`, `npm run typecheck:tsc`, targeted `npx vitest run <files>`, targeted `npx playwright test <spec> --project=chromium`; full suites at final wrap-up.
- Push after each phase; verify `Branch Continuous Release` workflow result via `gh run list --branch release/1.8.0/bucket-templates-ux --limit 3`.
