# v1.10.0 — Invite links, mobile nav, UX polish, and content densification

Approved in chat on 2026-08-26. Delivery: one PR on
`release/1.10.0/invite-links-ux-content`, phased commits (A→E).

## A. Invite links subsystem

One collection, one shape, three kinds. `inviteLinks/{tokenId}`:

- `tokenId`: crypto-random 128-bit hex — the URL is the secret.
- `kind`: `'bucket' | 'friend' | 'group'`
- `createdBy`, `createdByName`, `createdAt`, `expiresAt`, `revoked`
- bucket: `bucketId`, `bucketTitle`, `role` (default contributor)
- group: `groupId`, `groupName`
- Expiry: bucket 7 days, friend 24 h, group 24 h. Multi-use until expiry
  or revocation. Redemption is idempotent — already joined/friends is
  success, not an error.

Two callables (`functions/src/inviteLinks.ts`):

- `createInviteLinkV1100({kind, bucketId?, groupId?, role?})` — requires
  auth; bucket links require bucket ownership, group links group
  ownership; anyone creates their own friend link. Returns `{url, token,
  expiresAt}`.
- `redeemInviteLinkV1100({token})` — requires auth; validates
  expiry/revocation; performs the grant (bucket access grant with stored
  role, reusing the join-code grant path), mutual friendship, or active
  group membership. Returns a `{kind, ...}` result the UI narrates.
- `revokeInviteLinkV1100({token})` — creator only.

Firestore rules: `inviteLinks` readable/writable by no client except
reads by `createdBy` (to list/revoke own links). All redemption goes
through the callable with admin rights, so the token never has to be
client-queryable.

Routing: `/join/:token` (locale-aware variants included) inside the
authenticated app. Unauthenticated visitors are sent to login with a
`returnTo` that survives login *and* signup. The redemption screen shows
what the link grants ("Join bucket X as contributor", "Add Ihab as a
friend", "Join group Y") with a single confirm button, then navigates to
the granted resource.

Deep links: Android App Links (`.well-known/assetlinks.json` served by
Vercel + intent filter for `https://<origin>/join/*`), iOS Universal
Links (`apple-app-site-association` + Associated Domains entitlement —
config shipped, untestable without macOS, EXC-5), Capacitor `appUrlOpen`
handler routes into `/join/:token`. Browser/PWA hits the route natively.

Group join-by-identifier: each friend group carries a permanent
`joinCode` (owner-regenerable). The groups page gains a "Join a group"
input accepting that code. No global name search (approved: code/link
only).

Join-with-code for buckets stays exactly as it is.

## B. Mobile nav

The app bottom bar becomes horizontally swipeable and mirrors the
sidebar's public links: Home first, then Dashboard, Buckets, Members,
Orders, Settings, then About and Contact, the public entries navigating
to the locale-correct marketing pages.

## C. Polish

- Spacing under the buckets search field and the All/My/Shared segmented
  control.
- Notification center rows: full two-line text, aligned unread dots,
  vertical rhythm.
- Edge-stuck panels (marketing footer included) become rounded inset
  cards like the rest of the UI.
- Boot screen: circular spinner only. Skeletons remain solely inside
  lists/cards/tiles and mirror the shape of the content they become.
- Every mutating button: busy spinner + disabled until its toast fires.
- Public topbar: borderless theme toggle, globe icon on the language
  select, "Open App" label, Login and Signup links; the app redirects
  already-authenticated visitors to the dashboard.

## D. In-app page descriptions

Each app page gets a one-to-two sentence purpose description under its
heading, in all 13 locales, teaching the flow ("Create a bucket, share
it with friends or groups, start a round…").

## E. Marketing guides and SEO

Six new prerendered guide pages × 13 locales (create a bucket, share a
bucket, run an order round, split the receipt, invite friends, work with
groups), each with stepwise content, images with alt text, FAQ, and the
existing OG/hreflang/sitemap treatment. Home, features, and FAQ pages
densified. The exactly-10-pages validator becomes a minimum. Quality
over count: six deep pages beat fifteen thin ones for AdSense.

## Out of scope

Global group name search (privacy), changes to join-with-code, iOS
on-device Universal Link verification (EXC-5).
