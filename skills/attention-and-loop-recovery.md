# Skill — Attention and loop recovery

Trigger when activity is high but acceptance progress is unchanged, or when commands, reads,
errors, edits, plans, critics, context reloads, or approaches repeat without new evidence.

1. Stop the current branch.
2. Restate objective, Definition of Done, completed requirements, remaining requirements, and blocker.
3. Compare recent actions and name the unchanged outcome.
4. Remove speculative branches and classify the branch that caused drift.
5. Reduce the problem to the smallest reproducible blocker.
6. Choose a materially different hypothesis, layer, evidence source, or isolation method.
7. Retry once with the new strategy.
8. Resume the smallest deliverable, or report the exact blocker and proof.

Recovery must reduce active branches and assumptions. It must not create five new hypotheses.
