# Skill — Executive function

Use before planning, auditing, editing, testing, review, or delegation.

1. Lock the exact objective and observable success condition.
2. Write the minimum finite Definition of Done.
3. State included/out-of-scope work.
4. Select one active work item and its smallest meaningful deliverable.
5. Record blocker, nesting depth, retry count, critic round, and verification state.
6. Execute the delivery loop: understand enough → implement → targeted proof → checkpoint.
7. Classify discoveries as blocker, required, optional, or unrelated; park the last two.
8. Trigger recovery after repeated strategy, reread, edit/revert, replan, critic, or test loops.
9. Run risk-appropriate final gates.
10. Stop when the Definition of Done is proven.

Defaults: WIP `1`, nesting `3`, same-strategy attempts `3`, critic rounds `2`, full replans `2`, delegation depth `2`, stalled cycles `4`.
