# FoodOrderV1 v1.9.1

A focused UI/UX and delivery-speed release that makes ordering easier while preserving the advanced collaborative workflows.

## Highlights

- Reworked order creation into a guided three-step flow on one route: choose items, add notes, then review and confirm.
- Added visible recent/frequent item autocomplete in bucket creation and editing, with a clear 🔥 indicator and frequency counts.
- Refreshed both light and dark themes with warmer food-oriented colors, stronger hierarchy, clearer surfaces, and improved mobile behavior.
- Rewrote key Egyptian Franco/Arabizi screens using natural mainstream wording and familiar product terms such as order, menu, group, share, invite, settings, and total.
- Improved Firebase release planning so UI/content/i18n-only releases skip Firebase entirely, while Firebase changes still deploy only required targets when safe.
- Kept the full release integrity, security, regression, Firebase rules, Functions, E2E, cross-browser, and APK gates.
