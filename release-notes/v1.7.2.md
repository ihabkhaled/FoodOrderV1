# FoodOrderV1 v1.7.2

Multilingual public discovery, richer marketing contact paths, and faster Vercel builds.

## Highlights

- Added locale child sitemaps, bounded localized RSS feeds, and autodiscovery.
- Added a localized, accessible contact form with a validated SMTP serverless boundary.
- Preserved the existing twelve-locale registry and private-route indexing boundaries.
- Limited Vercel to the deployable `build:web` path; hooks and CI retain quality gates.
- Added an external prompt-pack adaptation playbook and single-source version guidance.
- Improved dark-theme contrast, mixed Arabic/Latin activity layout, member/status pills,
  compact language controls, and native dropdown theming.
- Removed storage-provider details from client-facing shell, authentication, and settings
  surfaces; users see connection state and the package-derived app version.

## Public discovery

- 120 reviewed public documents across the existing 12 supported locales.
- Sitemap index at `/sitemap.xml` with one bounded child sitemap per locale.
- Localized feeds at `/{locale}/feed.xml` and `/{locale}/feeds/topics.xml`; English uses
  `/feed.xml` and `/feeds/topics.xml`.
- RSS autodiscovery metadata and public-footer feed links.
- Canonical production remains indexable while preview and local deployments remain
  globally noindex.

## Contact and deployment

- Contact copy, subject, in-place submission status, and accessible form controls are
  localized across all supported locales.
- `/api/contact` validates method, body size, field limits, email shape, SMTP
  configuration, honeypot input, and best-effort per-instance rate limits.
- Auth and app sidebars link to the localized welcome and contact pages; the login
  controls include a public-home icon.
- Vite development exercises real Ethereal SMTP delivery and logs its safe preview URL,
  while production remains locked to configured recipient SMTP credentials.
- Contact delivery remains disabled until sensitive SMTP variables are configured.
- Password-reset messages use the configured SMTP sender; Firebase Admin only creates
  their secure one-time reset action codes.
- Vercel now runs `npm run build:web`; repository checks remain enforced by Husky and CI
  instead of being duplicated during deployment.

## Validation

- Both TypeScript compilers, lint, formatting, i18n parity, release integrity, dead-code
  and circular-dependency gates passed.
- 335 unit/integration tests and 17 Functions tests passed.
- Coverage passed at 91.86% statements, 82.16% branches, 95.21% functions, and 94% lines.
- 117 Chromium/mobile/tablet tests and 54 Firefox/WebKit/mobile-Safari tests passed; one
  existing WebKit loading assertion passed on retry.
- The production build, public generator, public artifact validator, and Capacitor sync
  passed.

## Known limitations

- Native iOS compilation remains unavailable on the Windows development host (EXC-5).
- Production contact delivery requires sensitive SMTP variables and platform rate limiting.
- Firestore emulator validation was unavailable locally because Java was not present on
  `PATH`; no Firestore rules changed.
- React Router's RSC-only HIGH advisory has no compatible fixed v7 release and does not
  affect this Vite SPA. EXC-6 is exact-package scoped, fail-closed for all other findings,
  and expires on 2026-09-30.
