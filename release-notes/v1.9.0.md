# FoodOrderV1 v1.9.0

A dense usability, visual-design, SEO, delivery, regression, and AI-execution release for Gama3 Orderak.

## Highlights

- Simplified the first-use journey around three clear actions: create a bucket, invite people, and finalize the shared order.
- Strengthened the dashboard primary action while reducing the visual weight of analytics and advanced controls.
- Added modern responsive styling, clearer hierarchy, larger touch targets, stronger focus states, and improved mobile shell behavior.
- Reworked public marketing copy to explain the product quickly and improve conversion.
- Improved title, description, canonical, locale, Open Graph, Twitter card, shared-image dimensions, alt text, and structured public content.
- Added change-aware Firebase planning so frontend/content-only changes skip Firebase and isolated Firebase changes deploy only required targets.
- Added repository-wide AI executive controls for objective locking, scope preservation, evidence, bounded retries, deadlock/livelock recovery, concise communication, context routing, memory, verification, and termination.
- Added tooling coverage for the Firebase change planner and AI executive-function runtime.
- Preserved the existing advanced workflows: reusable buckets, roles, invitations, friend requests, contributions, group orders, notifications, pricing, receipts, repeat orders, offline support, English, Arabic, and RTL.

## Validation scope

- Knowledge build and validation.
- Translation, formatting, lint, TypeScript, unit/component/tooling, build, public-content, and release checks.
- Firebase Functions and Firestore-rule validation when selected by the change planner.
- Critical, social, responsive, cross-browser, and full group-order E2E flows.
- Authenticated multi-account regression across bucket sharing, friend requests, contributions, order finalization, notifications, and receipts.
