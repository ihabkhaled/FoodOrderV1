# FoodOrderV1 v1.8.0

Reusable bucket templates, safer account actions, honest privacy controls, and a
calmer, better-explained interface.

## Highlights

- Buckets are reusable order templates. "Start round" opens a new order session
  from a shared bucket, seeds the same members automatically, and notifies each
  of them — the template itself is never renamed, consumed, or duplicated, so
  the same menu can run every week.
- Duplicating a bucket now keeps its exact title; the "(copy)" suffix is gone.
- Replaced the "0" trap in every money and percentage field: a zero renders as a
  placeholder, so typing `14` produces `14` instead of `014`.
- Logging out asks for confirmation and shows a busy state while the session
  ends, instead of signing out on a single mis-tap.
- Deleting an account now requires re-entering the account email and password;
  nothing is deleted until those credentials verify, in both Firebase and
  local-device modes.
- Split the single dense settings screen into a hub with four focused subpages:
  preferences, privacy, security, and data & account.
- Language and theme restore from the signed-in profile on a new device, and the
  `system` theme now follows live operating-system light/dark changes.
- Analytics consent controls a real, consent-gated sink: diagnostics are written
  to a capped device-local window that never leaves the device, and the privacy
  screen shows the exact stored count with a clear action.
- Each screen loads section by section. The heading, filters, and actions paint
  immediately while individual sections show their own placeholders, and the two
  bucket collections now resolve independently of each other.
- In-app notifications mirror into the operating-system notification tray while
  the app is in the background, and tapping one opens its destination in the
  app. Permission is only ever requested from a deliberate user action.
- Guided tours introduce all nineteen screens — dashboard, buckets, the bucket
  editor, sharing, collaboration, joining, orders, order details, order
  creation, order rounds and their details, social, and every settings page.
  Each opens once per screen, dims the page behind it, and highlights the
  element being explained where there is one. Any tour can be dismissed
  permanently and all of them replayed from Settings → Preferences.

## Validation

- Vitest unit and component suites (382 tests), including new coverage for the
  numeric field, the re-authentication dialog, the diagnostics recorder, the
  skeleton primitive, and the tray-mirroring selector.
- Firestore rules tests against the emulator, covering the new optional
  `analyticsConsent` profile field.
- Firebase Functions tests (18), covering the order-round notification fan-out.
- Playwright: 180 tests across Chromium desktop, Pixel 7, and iPad Mini, plus
  the Firefox, WebKit, and mobile-Safari cross-browser matrix.
- Manual browser walkthrough of registration, bucket creation, settings, privacy
  diagnostics, and the account-deletion gate, with no console errors or
  warnings.
- Android debug APK built locally against the new local-notifications plugin.

## Known limitations

- Native iOS validation still requires macOS/Xcode (EXC-5). The
  local-notifications plugin ships in `Package.swift`, but iOS notification
  behaviour is unverified.
- Notification mirroring covers a backgrounded app, not a fully closed one.
  Remote push needs a VAPID key, `google-services.json`, and APNs assets that
  live outside this repository; the prerequisites are documented in
  [docs/operations/push-notifications.md](../docs/operations/push-notifications.md).
- Adding `@capacitor/local-notifications` expands the Android permission surface
  by `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED`, and `WAKE_LOCK` through
  manifest merging; see
  [docs/migration/native-security-audit.md](../docs/migration/native-security-audit.md).
- The in-app brand name still reads "FoodOrder" while the native app is
  "Gama3 Orderak". Renaming the in-product copy across all 12 locales is a
  branding decision and was left for the owner to confirm.
